1. **Activate SUZIE AI Agent V1 — runtime, memory and GitHub workflow (#4)**  
   Implement the SUZIE AI Agent V1 as described in English and Thai specification files. The agent should provide a least-privilege runtime environment, persistent provenance tracking, issue triage, PR proposal generation with review checkpoints, testing, audit logs, and explicit operational status reporting.    [Link](https://github.com/uicp-protocol/constitution/issues/4)

2. **Research: GDH measurement specification v0.1 (#3)**  
   Develop a transparent and testable definition of Gross Domestic Happiness (GDH). This includes human well-being evidence, uncertainty quantification, sampling methodologies, and measures for inequality and suffering. AI or non-human subjective experiences are excluded unless validated.  
   [Link](https://github.com/uicp-protocol/constitution/issues/3)

3. **Research: Define an inclusive consensus specification (#2)**  
   Propose a protocol specifying eligibility, identity verification, unanimous consent for adding new constitutional pillars, handling of abstentions and deadlocks, accessibility considerations, and protection against sybil attacks. This protocol should keep deliberation processes separate from constitutional ratification. No current implementation exists.  
   [Link](https://github.com/uicp-protocol/constitution/issues/2)

4. **Welcome: Open discussion on the UICP founding draft (#1)**  
   Invites public discussion on the UICP Draft v0.1 in all languages. Readers are encouraged to review the English and Thai versions and share questions, criticisms, references, or proposals. Contributions do not constitute binding votes. Privacy is emphasized.  
   [Link](https://github.com/uicp-protocol/constitution/issues/1)
