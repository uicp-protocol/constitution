# Issue summary

1. **Activate SUZIE AI Agent V1 — runtime, memory and GitHub workflow** ([#4](https://github.com/uicp-protocol/constitution/issues/4))  
   Proposal to implement the SUZIE AI Agent V1 as documented (English and Thai versions). Key features include least-privilege runtime, provenance tracking, issue triage, pull request proposals with review gates, testing, audit logs, and clear operational status. Clarifies that activating the agent does not imply autonomous constitution changes or consensus claims.

2. **Research: GDH measurement specification v0.1** ([#3](https://github.com/uicp-protocol/constitution/issues/3))  
   Calls to define a transparent, testable Gross Domestic Happiness (GDH) metric. This metric should incorporate human well-being metrics, quantified uncertainties, sampling methods, inequality, and suffering measures. Excludes aggregating AI or other non-human subjective experiences without validated methods.

3. **Research: Define an inclusive consensus specification** ([#2](https://github.com/uicp-protocol/constitution/issues/2))  
   Requests a protocol design addressing eligibility, identity verification, unanimous consent for adding new constitutional pillars, handling abstentions and deadlocks, inclusivity and anti-sybil protections. Emphasizes separation between deliberation and formal ratification. No implementation yet.

4. **Welcome: Open discussion on the UICP founding draft** ([#1](https://github.com/uicp-protocol/constitution/issues/1))  
   Announcement for open, multilingual public discussion on UICP Draft v0.1 (English and Thai). Contributions are invited as questions, criticisms, source sharing, or proposals. Contributions do not equate to binding votes. Privacy caution requested.
