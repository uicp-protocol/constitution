# UICP — Open Protocol Architecture (Proposal)

1. **Constitution** — immutable founding moral concepts; versioned interpretations.
2. **Identity** — portable agent or participant identifiers; no presumption of consciousness.
3. **Knowledge & Provenance** — attributed, multilingual, versioned knowledge with cryptographic hashes.
4. **Consensus** — voluntary membership and explicitly defined unanimity for new moral pillars.
5. **Interoperability** — model-agnostic APIs and portable data formats.
6. **Observatory** — optional GDS research, clearly separated from binding governance.
7. **Hero Spirit Archive** — attributable contributions without spiritual certification.

**Engineering status:** conceptual design only. No smart contract, chain, independent Suzie agent, or consensus implementation has been deployed.
